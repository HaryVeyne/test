# Project Unknown · 未知之境 V0.3

Godot/C# 原生 Windows 单人动作探索 RPG。地表 220×220 格，包含五种区域、原有遗迹机关和两个地下城。V0.3 新增四档难度、武器伤害克制、湿地排水事件、特殊装备和快捷操作。

## 启动

Windows 下载：[V0.3 发布页](https://github.com/HaryVeyne/test/releases/tag/v0.3.0)，选择 `ProjectUnknown-V0.3-Windows-x64.zip`。

下载 Windows 包后完整解压，运行 `Windows/ProjectUnknown.exe`，保留同目录的运行库和数据文件。玩家不需要安装 .NET SDK。

开发环境保持 **Godot 4.6.3 .NET + .NET 8 SDK**。在 Godot 中导入根目录 `project.godot`，等待资源导入，构建后按 **F5**。也可执行：

```sh
dotnet build ProjectUnknown.csproj
godot --path .
```

`godot` 必须指向 .NET 版，标准版不支持本项目的 C# 脚本。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 奔跑 | WASD 或方向键 / Shift |
| 攻击方向 / 普通攻击 | 鼠标 / 鼠标左键，可按住连续攻击 |
| 切换当前与备用武器 / 使用药水 | Tab / Q |
| 芦苇长弓蓄力 | 按住鼠标右键，松开发射 |
| 闪避 | Space |
| 回旋斩 / 三连射 / 寒霜爆发 | 1 / 2 / 3，需先学习对应技能 |
| 互动、开箱、拾取、休息 | E |
| 背包 / 角色与技能 | I / C |
| 地图 / 探索日志 | M / J |
| 暂停 / 全屏 | Esc / F11 |

初始背包含剑、弓、法杖和药水。背包可装备、卸下、使用或丢弃物品；丢弃物品可在原地拾回。等级提升获得技能点，角色页可学习主动技能及三种被动强化。

完成中央遗迹并击败两个地下城 Boss 即完成主线，结算后可继续探索。营地恢复生命、设置复活点并解锁快速旅行；附近有敌人时无法休息或旅行。死亡保留装备、经验和已完成进度。击败的敌人在此存档中不会刷新。

## 难度与战斗选择

新游戏可直接选难度，游戏中可在设置里调整；战斗中禁用切换。难度随存档保存，切换时保持敌人的剩余生命比例，已经死亡的敌人不会复活。敌人攻击预警时长不变。

| 难度 | 敌人生命 | 攻击 | 防御加成 | 移速 |
| --- | --- | --- | --- | --- |
| 轻松 | ×0.80 | ×0.75 | -1 | ×0.95 |
| 标准 | ×1.00 | ×1.00 | 0 | ×1.00 |
| 困难 | ×1.35 | ×1.30 | +2 | ×1.08 |
| 极难 | ×1.65 | ×1.60 | +4 | ×1.12 |

斩击对野兽 ×1.25，穿刺对轻甲 ×1.20，奥术对重甲 ×1.30，火焰对植物 ×1.35；重甲抵抗斩击与穿刺，植物抵抗穿刺与寒霜，野兽抵抗寒霜。倍率作用于伤害，再扣除防御，至少造成1点伤害。普通攻击、范围爆炸及三个主动技能都使用对应类型；鼠标指向附近敌人可查看弱点、抗性和当前武器倍率，背包显示武器类型。

湿地营地附近新增排水泵站，事件会改变库房和近路的通行状态。芦苇长弓蓄满0.7秒后发射1.8倍伤害的穿透箭；薄霜护符让闪避后2秒内的首次普通攻击附加减速；库房守卫掉落对重甲有效的水闸法杖。守卫长剑第三击破甲3秒，忽略防御但保留伤害抗性。熔炉热地板也会伤害敌人，可利用预警引敌。

## 存档

存档自动保存，也可在暂停菜单保存和导出 JSON 探索记录。兼容 V0.1、V0.2：旧档默认为标准难度，保留已有进度，补充备用武器；V0.1 还会迁移地图探索索引及角色数据。旧档位置若落在新增的湿地水域，会移至附近可通行位置。新游戏会先备份旧档；损坏存档不会被自动覆盖。

Windows：`%APPDATA%/ProjectUnknown/`；Linux：`~/.local/share/ProjectUnknown/`。装备、成长、地下城、检查点和地面掉落均保存；战斗冷却和存活敌人的当前生命在重新载入区域时重置。

## Windows 导出

安装匹配的 **4.6.3 .NET** 导出模板，在“项目 → 导出”选择已有的 **Windows Desktop** 预设，导出到 `Builds/Windows/ProjectUnknown.exe`，分发整个目录并附带字体授权。Linux/macOS 可运行：

```sh
GODOT_BIN=/path/to/godot-mono tools/export-windows.sh
```

需要 `dotnet` 在 PATH 中。脚本执行导入、Release 构建、Windows x64 自包含导出并复制字体授权。中文字体为 Noto Sans CJK，授权见 `Assets/Fonts/LICENSE-NotoSansCJK.txt`。

GitHub Actions 的 **Windows V0.3 release** 流程固定使用 Godot 4.6.3 .NET 和 .NET SDK 8.0.425，运行集成检查、导出并上传到 `v0.3.0` 发布草稿，然后发布。首次由 `ci/windows-release-v03` 分支推送触发；合入默认分支后也可在 Actions 页面手动运行。需要已有的发布草稿，已公开版本不会被覆盖。
